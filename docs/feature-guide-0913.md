# AWOS 기능 설명서 (2026-09-13 기준)

지금까지 만든 기능을 화면 순서대로 하나씩 적었어요. 팀원·TS·투자 설명에 그대로 쓰실 수 있게 전문용어는 풀어 썼어요.

- 버전: v2.9b · 파일 222개 · SQL 22개 · 테스트 129건(단위 109 + 브라우저 20)
- 주소: aviationwallet.com · 안드로이드 앱(비공개 테스트 중)

---

## 한 줄 요약

**종이 로그북과 자격증 지갑을 하나로 옮긴 앱.** 비행을 기록하면 교관이 앱에서 서명하고, 자격증은 사진 한 장으로 등록되고, "오늘 이 비행 해도 되나"를 법령 기준으로 자동 판정해 줍니다.

# 1. 조종사 화면

로그북은 탭 6개예요. 자격 구분(항공기 / 경량항공기 / 초경량)을 위에서 고르면 그 구분의 기록만 따로 계산됩니다. 섞이지 않아요.

## 1-1. 비행기록 탭 — 내 기록 전체

- **기록 목록**: 날짜·기종·구간·시간이 카드로 쌓여요. 배지로 한눈에 구분 — `X-C`(크로스컨트리) / `LCL`(장주) / `NGT`(야간) / `FTD`(시뮬레이터), `교관 서명 완료`, `해외 기록`, `이월 기록`.
- **필터**: 전체 / 미서명 / 기종·월·구분별. "미서명"은 교관 서명이 아직 없는 것만 골라 줘요(이월·해외 기록은 서명 대상이 아니라 빠져요).
- **총 비행시간 요약**: 총시간, 기종 등급별(단발·다발·회전익), 임무별(Dual·기장·SIC·교관), 조건별(주간·야간·크로스컨트리·야간 크로스컨트리·실제계기·모의계기), 시뮬레이터, 착륙 횟수.
- **CSV 백업**: 전체 기록을 엑셀로 내려받아요.
- **비행경력증명서 PDF**: 시행규칙 별지 제36호서식 그대로 그려서 내려받아요. 표 칸(기장/부조종사/교관/학생조종사, 주간·야간 × 시계·야외)까지 법정 서식과 같게 채워요. 출력물에는 "초안 · 발급기관 확인 전"이 인쇄돼요 — 학교 확인 전에는 효력이 없다는 뜻이에요.
- **기록 상세**: 값을 고치거나 지울 수 있고, 교관에게 서명을 요청할 수 있어요.

## 1-2. 기록 입력 탭 — 새 비행 적기

- **기본**: 날짜, 기종, 등록번호, 출발→도착, 블록타임, 착륙 횟수(주간·야간).
- **등급별 시간**: 육상단발 / 육상다발 / 회전익 — 커런시와 응시경력이 등급별로 계산되기 때문에 나눠 적어요.
- **임무별 시간**: Dual(교육받은 시간) / 기장(PIC) / SIC / 교관. `2인 조종 항공기` 체크가 있는데, 체크 안 하면 SIC 시간이 응시경력에서 절반만 인정돼요(시행규칙 제78조).
- **조건별 시간**: 주간·야간·크로스컨트리·**야간 크로스컨트리**·실제계기·모의계기. 주간과 야간은 하나를 넣으면 나머지가 자동으로 채워지고, 야간 크로스컨트리는 야간과 크로스컨트리 중 작은 값으로 자동으로 들어가요(고칠 수 있어요).
- **시뮬레이터 모드**: FTD·AATD·FFS를 고르면 출발·도착지 같은 칸이 사라지고 장치 종류와 시간만 적어요. 장치마다 응시경력 인정 상한이 달라서(별표 4) 구분해 둡니다.
- **학생 단독비행 체크**: 자격증 없는 학생이면 "단독비행" 체크가 나와요. 체크하면 기장+단독 시간으로, 안 하면 교관 동승 교육으로 기록돼요.
- **해외 기록 체크**: 미국 등 외국에서 한 비행. 국내 교관 서명 대상이 아니라 서명 요청이 가지 않아요.
- **저장하면서 바로 서명 요청**: 저장 버튼 위에서 교관을 고르면, 저장과 동시에 그 교관 서명함으로 요청이 갑니다. 안 골라도 나중에 기록 상세에서 보낼 수 있어요.

### 과거 기록 가져오기 (같은 탭 아래)

두 가지 길이 있고, 성격이 달라요.

| | 엑셀로 가져오기 | 비행경력증명서로 가져오기 |
|---|---|---|
| 무엇 | 탈론 등에서 내려받은 비행 목록 | 학교가 발급한 증명서 한 장(합계) |
| 결과 | 개별 기록으로 들어감 | "이월 기록" 한 건 |
| 확인 | 관리자 확인 없음(참고 기록) | **관리자가 증명서와 대조해 승인** |
| 쓰임 | 내 기록 관리용 | 공식 총 비행시간 |

**엑셀 가져오기**는 열 이름을 보고 자동으로 맞춰 줘요. 못 맞히면 열마다 직접 고를 수 있고요. 서식 차이도 읽어요 — `1:30`·`1시간 30분`·`90분` 같은 표기, 분 단위로만 적힌 열(90 → 1.5시간 자동 감지), 미국식 날짜(7/1/2025), 두 자리 연도, 엑셀 날짜 일련번호. 하단의 합계·서명 행은 자동으로 빼요.

**비행경력증명서 가져오기**는 사진이나 PDF를 올리면 AI가 칸을 채웁니다(아래 3장 참고).

## 1-3. 자격증 탭 — 디지털 자격 지갑

- **마스터 카드**: 실물 자격증 모양 그대로 자격명·번호·한정사항·제한사항을 카드로 보여줘요. 조문 번호도 같이 표시해요.
- **등록 가능한 것**: 조종사 자격증명, 한정 추가, 계기비행증명, 조종교육증명, 항공신체검사, 항공영어구술능력증명, 무선통신사, 조종연습허가서, 법정교육, 교관 확인, 기타.
- **만료 관리**: 만료일이 가까우면 카드에 경고가 떠요. 신체검사는 발급일만 넣으면 별표 8 기준(2종 40세 미만 60개월·40대 24개월·50세 이상 12개월, 1종 12개월)으로 만료일이 자동 계산돼요. 그 달 말일까지로 잡는 규칙까지 반영돼 있어요. 항공영어는 등급별(4등급 3년·5등급 6년·6등급 영구)로요.
- **AI로 읽기**: 자격증 사진 한 장을 올리면 자격명·번호·발급일·만료일은 물론, **한정사항에 적힌 육상다발·계기비행증명·조종교육증명·항공영어까지 찾아서** "같이 찾은 자격" 체크 목록으로 보여줘요. 체크한 것은 같은 사진으로 함께 등록돼요. 이미 등록된 건 자동으로 체크가 꺼져요.
- **중복 방지**: 같은 자격번호(또는 같은 이름·종류·등급)면 저장이 막혀요.
- **여러 장 첨부**: 앞·뒷면처럼 여러 장을 한 번에 올릴 수 있고(최대 4장), AI가 전부 같이 읽어요.
- **관리자 인증**: 등록하면 관리자에게 요청이 가고, 사진과 대조해 승인하면 `인증됨` 표시가 붙어요. 인증된 자격만 커런시·적합성 판정에 쓰여요.
- **교관 확인(Endorsement)**: 단독비행 확인, 야간 단독, 단독 야외비행, 응시 전 확인 등을 **교관이 앱에서 직접 서명**해요. 학생이 종류를 고르고 교관을 지정하면 그 교관 서명함으로 가고, 교관이 손글씨로 서명하면 `교관 서명됨`이 붙어요. 학생이 "받았다"고 자기 신고하는 게 아니에요.

## 1-4. 커런시 탭 — 지금 비행할 수 있나

법령 기준으로 네 가지를 계산해요. 각 항목은 접었다 펼 수 있어요.

1. **항공신체검사**: 유효한지, 며칠 남았는지.
2. **최근 비행경험** (운항기술기준 8.2.2 / 시행규칙 제121조): 일반은 180일 이착륙 3회, 운송·사용사업은 90일 이착륙 3회 + 야간 1회. **등급별로 따로 판정**해요 — 단발은 되는데 다발이 안 되면 "일부 충족"으로 보여줘요. 한정이 없는 등급은 "한정 없음"으로 표시하고 GO에서 빼요(한정 없이는 교관 감독 아래 조종연습만 가능하니까요). 미달이면 회복 조건(교관 동승 2시간·이착륙 3회)을 알려줘요.
3. **계기비행 경험** (8.2.3): 6개월 안에 계기접근 6회 + 계기비행 6시간. 계기 심사를 받았으면 6개월 인정.
4. **조종교육 경험** (제125조): 교관은 1년에 10시간. 신임 교관은 유예 표시.

**GO-TO-FLY 배지**가 맨 위에 크게 떠요. 하나라도 가능하면 GO이고, 안 되는 등급은 칩으로 따로 보여줘요. 참고 판정이고 최종 판단은 규정과 공단 기준이라는 안내가 같이 있어요.

**착륙 횟수가 안 적힌 기록**은 0회로 치지 않고 판정에서 빼요(해외 증명서엔 착륙 횟수가 없는 경우가 많아서요). 몇 건을 뺐는지 알려줘요. 지정 장치가 아닌 시뮬레이터(FTD·BATD) 착륙도 빼요.

**승무시간 한도 카드**: 별표 18 기준(24시간 8시간 · 28일 100시간 · 365일 1,000시간)으로 오늘 몇 시간 더 탈 수 있는지 보여줘요. 이건 사업자 의무라서, 자가용·훈련이면 GO/NO-GO 대신 "참고"로 표시해요.

## 1-5. 응시경력 탭 — 다음 자격증까지 얼마나

별표 4의 응시경력을 **118개 요건**으로 쪼개서 진척도를 보여줘요. 자가용 → 사업용 → 운송용 → 계기비행증명 → 조종교육증명(초급·선임) → 지도조종자 순서로요.

- 총시간, 기장시간, 야외비행(구간 거리 조건 포함), 계기, 야간, 단독, 착륙 횟수 같은 항목마다 "지금 얼마 / 필요한 만큼"을 막대로 보여줘요.
- **전문교육기관 이수자 감면**을 반영해요(자가용 40 → 35시간, 사업용 200 → 150시간 등).
- **시뮬레이터 인정 상한**이 장치별로 다르게 적용돼요(자가용 5시간, 사업용 20시간, 운송용 100시간 등).
- **다른 종류 항공기 경력 인정**(1/3 또는 상한 중 적은 쪽)도 계산돼요.
- 경량항공기 조종사 응시경력(별표 4 제2호)도 따로 있어요.

## 1-6. 서명 요청함 탭 — 교관에게만 보임

승인된 교관에게만 나오는 탭이에요. 학생이 보낸 서명 요청이 쌓이고, 내용을 확인한 뒤 **손글씨로 서명**하면 학생 기록에 반영돼요. 반려도 가능하고, 처리한 이력이 남아요.

# 2. 교관 전자서명 — 이 앱의 핵심

종이 로그북에서 교관이 사인하던 걸 그대로 옮긴 기능이에요. 법적 근거는 시행규칙 제77조①(비행이 끝날 때마다 기장·감독자가 증명)이에요.

**흐름**
1. 학생이 기록을 저장하며 교관을 고르거나, 나중에 기록 상세에서 요청
2. 교관 서명함에 뜸 → 교관이 내용 확인 → 손글씨 서명
3. 학생 기록에 `교관 서명 완료` 배지 + 서명 이미지

**증거로 남기는 방식**
- 서명하는 순간의 기록 내용을 **통째로 복사해 저장**하고 **SHA-256 해시**를 붙여요. 나중에 기록을 고쳐도 "서명 당시엔 이랬다"가 서버에 남아요.
- 서명 후 시간·날짜를 고치면 **서명이 자동으로 풀리고**, 바뀐 내용과 서명 당시 내용을 나란히 보여줘요.
- 서명·반려·취소 이력은 지우지 않고 쌓여요. 서명자 이름과 시각은 서버 시계로 기록돼요.

**서버에서 강제하는 규칙** (화면을 우회해도 막힘)
- 승인된 교관만 서명 가능, 자격 구분(항공기/경량/초경량)이 맞아야 함
- **자기 기록에는 자기가 서명 불가**
- 서명 이미지 없이는 승인 불가
- 지정된 교관 본인만 그 요청을 처리 가능

# 3. AI 문서 읽기

사진이나 PDF를 올리면 칸을 대신 채워 줘요. **판단은 하지 않아요** — 문서에 없는 값은 절대 만들지 않고 비워 둡니다.

**읽는 문서**: 조종사 자격증명서, 항공신체검사증명서, 무선통신사, 조종연습허가서, 비행경력증명서(한국 별지 36호·미국식 둘 다).

**비행경력증명서는 특별히 조심스럽게** — 별지 36호는 표가 복잡해서(주간·야간이 각각 4열) AI가 옆 칸을 집는 일이 있었어요. 그래서 이렇게 바꿨어요:

1. AI는 맨 아래 "계" 행의 칸 19개를 **왼쪽부터 순서대로 베끼기만** 해요. 합산하지 않아요.
2. **앱이 합산하고 검산**해요:
   - 주간 4열 + 야간 4열 = 소계
   - 기장 + 부조종사 + 학생조종사 = 소계
   - 교관 시간 ≤ 기장 시간
   - 단발 + 다발 + 회전익 ≈ 총시간
3. 검산이 맞으면 채우고 "검산까지 맞았어요"라고 알려줘요. 안 맞으면 **경고**하고 대조하라고 해요.
4. 교관조종사와 학생조종사가 바뀌어 읽히면 자동으로 되돌려요.

실제 증명서 값(오재헌·채지훈·AeroGuard)으로 **테스트를 박아 놔서**, 앞으로 코드를 고쳐도 이 계산이 틀어지면 바로 잡혀요.

**Dual(교육받은 시간)은 한국 증명서에 없어요.** 자격증 받은 뒤 교육받은 시간은 "기장"에 들어가 버리거든요. 그래서 비워 두고, "최대 얼마(소계 − 교관 − 부조종사)에서 혼자 탄 시간을 빼면 돼요"라고 알려줘요. 미국식 증명서는 Dual Received가 있으니 그대로 읽고요.

**개인정보**: 사진은 AI 처리를 위해 미국 서버로 갑니다. 그래서 **처음 쓸 때 동의 체크**를 받고, 개인정보처리방침에 국외 이전으로 적어 뒀어요. 모델 학습에는 쓰이지 않아요. 하루 10회로 제한해서 비용 사고도 막아요.

# 4. 관리자 화면 (대시보드)

탭 6개예요. 모두 검색창과 5건씩 페이지가 붙어 있어요.

1. **구성원 현황** — 가입자와 소속
2. **교관 승인 관리** — 조종교육증명을 확인하고 교관 권한을 줘요. 자격 구분별로 따로 승인해요(항공기 교관이라고 초경량에 서명할 수 있는 게 아니에요)
3. **비행경력증명서 승인** — 이월 기록을 증명서 사진과 대조해 승인. 승인 전엔 공식 총 비행시간에 안 들어가요
4. **자격증·신체검사 요청함** — 자격증 인증. 자격증/신체검사로 나눠 볼 수 있어요
5. **문의함** — 사용자 문의에 답장
6. **법령 관리** — 아래 5장

첨부 사진은 여러 장이면 나란히 보이고, 클릭하면 크게 열려요.

# 5. 법령 관리 — 법이 바뀌면 알려주는 기능

앱이 쓰는 법령 5건을 등록해 두고, 버튼 한 번으로 최신 여부를 확인해요.

**확인하는 것**
- 법령 전체의 현재 시행일 (국가법령정보센터 API)
- **우리가 쓰는 조문 16개 + 별표 3개가 바뀌었는지** — 조문 본문의 해시를 저장해 두고 비교해요. 별표는 PDF 파일 자체를 해시해요
- **앞으로 시행될 개정**이 있으면 노란 띠로 미리 알려줘요

**화면에 뜨는 것**
```
제77조 · 변경 없음    제121조 · 변경 없음    별표8 · 변경됨 — 원문 확인 필요
시행 예정 개정: 2026-11-13 시행 (일부개정)
```

각 법령 카드에는 **"코드에 들어 있는 값"**(예: 신체검사 60/24/12개월)과 **"코드 위치"**(고칠 파일 이름)가 적혀 있어요. 법이 바뀌면 어디를 고쳐야 하는지 바로 보여요.

**개정 대응 매뉴얼**: 탭에 "매뉴얼 복사" 버튼이 있어요. 누르면 문서가 복사되고, 새 AI 채팅에 붙여넣으면 그 AI가 이 프로젝트를 몰라도 법령 값을 고칠 수 있어요. 법령 값이 어느 파일 어느 함수에 있는지 표로 다 적혀 있거든요.

**값은 자동으로 안 고쳐요.** 기계는 "별표 8이 바뀌었다"까지만 잡고, "60개월이 48개월로 바뀌었다"는 사람이 읽고 판단해요. 그래야 틀린 값이 조종사에게 전달되지 않아요.

# 6. 계정과 개인정보

- **로그인**: 이메일, 카카오, 구글. 여러 방법을 한 계정에 연결할 수 있어요
- **계정정보**: 이름·연락처·생년월일·소속·자격 구분(여러 개)·운항형태
- **내 데이터 내보내기**: 비행기록·자격증·서명 이력을 JSON 한 파일로. 언제든 통째로 들고 나갈 수 있어요
- **회원 탈퇴**:
  - 누르면 먼저 "비행기록 N건을 CSV로 저장할까요?"를 물어봐요
  - 확인 체크 + 비밀번호(또는 확인 문구)를 받고 **즉시 삭제**
  - 지워지는 것: 계정, 연락처, 본인 로그북 전체, 자격증과 사진
  - **남는 것**: 상대방 기록 속 내 이름과 서명 기록. 종이 로그북에 상대방 이름이 남는 것과 같아요. 교관이 "내가 누구의 어떤 비행에 서명했다"를 증명할 수 있어야 하니까요(개인정보보호법 제15조①6호 정당한 이익). 화면엔 "탈퇴한 사용자"로 표시돼요

# 7. 눈에 안 보이지만 중요한 것들

- **내 기록은 나만** — 서버가 계정 단위로 막아요(RLS). 화면을 우회해도 남의 기록은 못 봐요
- **오프라인** — 기록이 기기에 먼저 저장되고 연결되면 서버로 올라가요. 비행기 모드에서도 앱이 열려요
- **PDF 한글 폰트** — 별지 36호를 한글 그대로 그리려고 폰트를 직접 만들어 넣었어요
- **모니터링** — 오류가 나면 관리자에게 알림(Sentry. 켜려면 설정 한 줄 필요)
- **테스트** — 단위 109건 + 브라우저 20건이 자동으로 돌아요. 코드를 고칠 때마다 GitHub에서 자동 실행돼요
- **법령 정확도** — 조문을 원문 PDF와 직접 대조했어요. 근거 없던 값("7일 35시간")은 찾아서 뺐고요. 화면에 나오는 조문 번호는 전부 실제 조문이에요
